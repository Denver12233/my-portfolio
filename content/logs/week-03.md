Week three has been all about data. I implemented several server components that fetch project data from our local JSON store. Learning the nuances of the Next.js App Router has been a steep but rewarding curve, especially around layouts and loading states.

I also worked on a project filtering system. I moved the filter logic into a pure utility function to keep the UI components clean and focused solely on rendering. This separation of concerns has already made the codebase much easier to test and maintain.
