## Overview

Week 3 was heavily feature-driven. The focus shifted toward building out the filtering and visualization capabilities of the system — features that directly affect how users explore and understand data relationships between universities, research papers, and startups. By the end of the week, I had also started working on user-facing pages like the signup flow and profile polishing.

## Day-by-Day

**February 23 — Filter Sidebar Implementation**

I started the week by adding two new filter sidebars to the system: "Filter by University" and "Filter by TBI." These sidebars allow users to narrow down the data they see based on specific institutions. Beyond just adding the UI components, I also wired up the additional functionality behind each filter to make sure the data responds correctly when a filter is selected. Building interactive filters that work cleanly with the existing data layer required careful attention to state management and component design.

**February 24 — Continued Feature Development**

This day was dedicated to continuing the feature additions started the previous day. With the filter sidebars in place, I worked on extending the system's capabilities further — refining edge cases, improving the filter behavior, and ensuring the new features integrated smoothly with the rest of the system without breaking existing functionality.

**February 25 — TBI & University Impact Radius with Visual Connections**

This was one of the more technically interesting days of the week. I implemented the TBI and University Filters to display the impact radius of specific institutions — giving users a visual sense of how far an institution's influence reaches. On top of that, I added visual lines connecting Universities to Research Papers to Startups, creating a visual lineage that makes data relationships immediately obvious. This kind of visualization transforms raw data into something meaningful and actionable for the end user.

**February 26 — University Signup Page and Shadow Profile Polishing**

The week closed with two tasks focused on the user-facing side of the system. I created the signup page for Universities, which is a critical entry point for institutional users into the platform. I also spent time polishing the Shadow Profile — refining its layout and content to make sure it presents cleanly and professionally to visitors.

## Key Takeaways

- Built and wired up "Filter by University" and "Filter by TBI" sidebars with full functionality
- Implemented impact radius visualization for TBI and University institutions
- Created visual connection lines linking Universities to Research Papers to Startups
- Developed the University signup page as a key user entry point
- Polished the Shadow Profile for a cleaner user-facing presentation
