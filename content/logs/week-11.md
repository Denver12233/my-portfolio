## Overview

Week 11 was a productive mix of technical refinement, system design thinking, and personal milestone work. The week carried forward the query ordering refactor from the previous week, introduced a PromptGraph Tiering proposal, delivered meaningful improvements to the QueryDetailsTable, and closed out with something personal — building the internship portfolio using Next.js.

## Day-by-Day

**April 27 — Query Result Ordering Refactor**

The week started by completing the refactor of result ordering in PromptGraph — grouping queries together and displaying their responses consecutively. This improvement made the AI Tracker's output significantly more readable and logical, giving users a clearer view of how the system was responding to each query.

**April 28 — System Design Analysis and Usability Enhancements**

With the refactor wrapped up, the focus shifted to a broader look at the system — analyzing existing design patterns and identifying opportunities to enhance performance and usability. This kind of review work is important for keeping the codebase healthy and ensuring the platform scales well as new features are added.

**April 29 — PromptGraph Tiering Proposal**

This day was spent creating a proposal for the "PG Tiering" ticket — a plan for how PromptGraph's tiering system should be structured. Putting together a proposal like this requires thinking through both the technical implementation and the product logic behind it, making sure the tiering design aligns with the platform's goals and user needs.

**April 30 — QueryDetailsTable Improvements and PR Submission**

I improved the QueryDetailsTable by adding timestamps, performance metrics, filters, and general cleanup — making it a much more useful tool for reviewing query data at a glance. After completing the improvements, I submitted PR #360 for review, putting the changes through the team's standard code review process.

**May 2 — Building the Internship Portfolio with Next.js**

The week closed on a personal note — building my internship portfolio using Next.js. This portfolio serves as a documentation of everything accomplished throughout the OJT, showcasing the projects, features, and skills developed during the internship at Makerspace InnovHub.

## Key Takeaways

- Completed the query result ordering refactor for better readability in PromptGraph
- Analyzed and enhanced system design for improved performance and usability
- Created a structured proposal for the PromptGraph Tiering system
- Improved the QueryDetailsTable with timestamps, performance metrics, and filters
- Submitted PR #360 for team review
- Built the internship portfolio using Next.js to document the OJT journey
