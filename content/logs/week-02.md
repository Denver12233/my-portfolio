## Overview

Week 2 was a mix of learning and building. The week started with an external seminar that broadened my perspective on the Philippine tech landscape, then shifted into focused development work — enhancing existing UI features and completing a significant map component for the project. By the end of the week, I had shipped real, visible features into the system.

## Day-by-Day

**February 16 — Philippine Coding Camp Seminar**

The week opened with attending the Philippine Coding Camp Seminar. It was an enriching experience that exposed me to the broader developer community in the Philippines — covering topics on modern development practices, career paths in tech, and the growing startup ecosystem. Events like this are a good reminder that development is not just about writing code, but also about staying connected with the community and keeping up with industry trends.

**February 17 — UI Feature Enhancements**

Back at the workstation, I focused on enhancing the system by adding three functional improvements: the Details view, the Impact Lineage UI, and the file download feature. Each of these added a layer of usability to the existing system. The Impact Lineage UI in particular required careful attention to how data relationships are displayed, making sure it was both accurate and easy to understand for end users. Completing all three in a single day was a good confidence boost.

**February 20 — Completed Phase 4 Map Component**

The week ended on a high note — I successfully completed the Phase 4 Map Component. Using Leaflet, the component now fetches and displays the location of each branch using its longitude and latitude coordinates. Seeing an interactive map render the correct branch locations in real time was one of the most satisfying moments of my internship so far. It also reinforced how powerful open-source mapping libraries like Leaflet are when integrated with a modern framework like Next.js.

## Key Takeaways

- Attended the Philippine Coding Camp Seminar and gained broader exposure to the local tech community
- Successfully delivered three UI feature enhancements in a single day
- Completed the Phase 4 Map Component using Leaflet with real geolocation data
- Learned how to properly configure Leaflet in a Next.js environment to avoid SSR conflicts
