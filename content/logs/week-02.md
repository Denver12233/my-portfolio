This week, I was tasked with building the primary navigation and button components. Following Atomic Design principles, I focused on creating flexible, composable atoms that can be used across the entire platform. Tailwind CSS has made styling these components extremely efficient.

One of the challenges I faced was ensuring accessibility for the dark mode toggle. I spent some time researching WCAG standards to make sure our color contrast passes the AA level. It's rewarding to see the UI start to come together with these small but essential pieces.
